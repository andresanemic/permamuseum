# Code not included / Código no incluido

## English

This public repository contains the project README, explanatory documents, a summary of recorded evidence, the review terms, social icons, and cover artwork. It does **not** contain Permamuseum’s source code, test files, or the raw reports from the excluded project workspace. The results in [Evidence](./docs/EVIDENCE.md) are a readable summary of records made available for this review; this repository cannot run or independently reproduce them.

The repository is published so Find Your Way and Meridian judges and other readers can understand the project’s design, follow its synthetic walkthrough, inspect the scope of its recorded checks, and see what the project does not claim. The example names and records are fictional. They do not indicate participation or approval by a real museum, artist, reviewer, or rights holder.

The project agreement says the code is intended to open during the judges’ review period under the review-only terms in [LICENSE](./LICENSE), for reading and cloning to evaluate it. This notice does not set a separate opening date or change those license terms. See [How it works](./docs/HOW_IT_WORKS.md) for the record model and [Legal and limits](./docs/LEGAL_AND_LIMITS.md) for claims the prototype cannot establish.

## Español

Este repositorio público contiene el README del proyecto, documentos explicativos, un resumen de la evidencia registrada, las condiciones de revisión, íconos sociales y la portada. **No** contiene el código fuente de Permamuseum, archivos de pruebas ni los informes brutos del espacio de trabajo excluido. Los resultados de [Evidencia](./docs/EVIDENCE.md) son un resumen legible de registros disponibles para esta revisión; este repositorio no puede ejecutarlos ni reproducirlos de forma independiente.

El repositorio se publica para que el jurado de Find Your Way y Meridian y otras personas puedan entender el diseño del proyecto, seguir el recorrido sintético, revisar el alcance de las comprobaciones registradas y conocer lo que el proyecto no afirma. Los nombres y registros del ejemplo son ficticios. No indican participación ni aprobación de un museo, artista, persona revisora o titular de derechos real.

El acuerdo del proyecto indica que el código está previsto para abrirse durante el periodo de revisión de los jueces, bajo las condiciones de solo revisión de [LICENSE](./LICENSE), para leerlo y clonarlo con fines de evaluación. Este aviso no fija otra fecha de apertura ni cambia las condiciones de la licencia. Consulta [Cómo funciona](./docs/HOW_IT_WORKS.md) para conocer el modelo de registro y [Marco legal y límites](./docs/LEGAL_AND_LIMITS.md) para saber qué no puede establecer el prototipo.
