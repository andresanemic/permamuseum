# Code not included

This repository currently contains project documentation and an evidence summary, not Permamuseum source code or the underlying test files. It is published so the Find Your Way and Meridian judges and the community can review the project before the code opens. The code will be opened during the judges’ review period under the review-only license in [LICENSE](LICENSE), for reading and cloning to evaluate it.

# Código no incluido

Este repositorio contiene por ahora documentación y un resumen de evidencia, no el código fuente ni los archivos de pruebas de Permamuseum. Se publica para que el jurado de Find Your Way y Meridian y la comunidad puedan revisar el proyecto antes de abrir el código. El código se abrirá durante el periodo de revisión de los jueces bajo la licencia de solo revisión de [LICENSE](LICENSE), para leerlo y clonarlo con fines de evaluación.
